# Hemispheres

**Category:** Forensics
**Difficulty:** Medium–Hard
**Flag format:** `csaw{...}`

---

We received an image. Just an image. Our analyst swears there's more to it,
but every tool says it's a perfectly ordinary PNG — it opens, it renders, it
looks like a picture.

They're not wrong. But they're not seeing everything. And even when you find
the second thing, it's locked — the key was never written down.

## Files

- `the_signal.png` — open it. Then look again. Then look *closer*.

## Hint

Different programs read a file from different ends. And a picture can carry
more than what it shows you — the words point at the pixels for a reason.
